# BabyBond Journal

Build a beautiful production-ready Android application named "BabyBond".



Purpose:

A real-time baby care tracker where both Mother and Father can track their newborn together from different phones.



This app must feel like a premium baby journal, not a hospital application.



Tech Stack

- Flutter

- Firebase Authentication (Phone OTP)

- Cloud Firestore

- Firebase Cloud Messaging

- SQLite Offline Cache

- Riverpod

- Material 3



Design

- Cute

- Modern

- Soft pastel colors

- Rounded cards

- Smooth animations

- One hand usage

- Dark Mode & Light Mode

- Premium UI similar to Google Pixel apps.



Authentication

- Phone OTP Login

- Family Account

- Invite Partner

- Both parents share one baby profile.

- Instant real-time sync.
