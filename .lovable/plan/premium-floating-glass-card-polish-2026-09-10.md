# Premium Floating Glass Card Polish

## What will change
- Introduce one restrained glass-card surface system using the existing warm palette, with readable translucency, hairline borders, shallow natural shadows, and a consistent modern radius.
- Apply that shared treatment to existing dashboard, tracker, timeline, report, profile, settings, insight, journey, album, milestone, and onboarding cards without rearranging pages.
- Standardize icon wells, card spacing, typography hierarchy, and subtle press/hover feedback where cards are interactive.
- Give existing live breastfeeding and sleep cards a slightly stronger treatment while keeping inactive states compact.
- Tune the same tokens separately for dark mode so borders and surfaces remain clear without heavy shadows or glare.

## Technical details
- Keep all data, timers, calculations, links, controls, cloud sync, offline behavior, and notifications unchanged.
- Centralize surface, border, shadow, and interaction values in the existing design tokens and shared card primitives.
- Preserve controls as visually distinct controls; no new state, records, routes, or dependencies.
- Validate representative screens at mobile width in light and dark mode, plus type checks and browser console state.
